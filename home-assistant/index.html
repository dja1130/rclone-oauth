homeserveransell Home Assistant

homeserveransell Home Assistant is a private, single-user Google OAuth client for Home Assistant, the open-source home automation software. It runs on one home server and lets its owner show their own Google Calendar events and Google Tasks on their own TV and screens at home.

It is not a public service: no one else can sign up for or use it, and it has no user interface beyond the owner's own Home Assistant on that server.

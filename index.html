homeserveransell rclone

homeserveransell rclone is a private, single-user Google OAuth client for rclone, the open-source file sync tool. It runs on one home server and lets its owner back up their own files to, and read their own folders from, their own Google Drive.

It is not a public service: no one else can sign up for or use it, and it has no user interface beyond the rclone command line on that server.
